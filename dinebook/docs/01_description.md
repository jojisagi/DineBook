# DineBook — Project Description

## Project Name
DineBook — Restaurant Table Reservation & Management System

## Problem Statement
Restaurants need a centralized system to manage table reservations, guest profiles, booking assignments, and no-show tracking. Manual or paper-based systems lead to double-bookings, lost reservations, and poor guest experience. DineBook solves this by providing a web-based management panel for hostess staff and a structured data model for all reservation operations.

## Target Users
- **Restaurant Hostess Staff**: Primary users who create, search, modify, and delete reservations, manage tables, assign bookings, and report no-shows.
- **Restaurant Managers/Admins**: Oversee operations, access reports, and manage guest CRM data.
- **Customers** (future deliverable): Will be able to make online reservations directly.
